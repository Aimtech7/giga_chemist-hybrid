# GIGA CHEMIST — SHOP 2 DEPLOYMENT DIRECTORY

This directory houses all artifacts, configurations, database scripts, migration tooling, and deployment packages for **Shop 2**.

## Directory Layout
- `README.md` — Overview of Shop 2 deployment system.
- `START-HERE.md` — Operator guide for preparing and installing Shop 2.
- `config/` — Safe templates and production configuration specifications.
- `database/` — Base database schemas, migration runners, and initial PostgreSQL scripts.
- `installer/` — Windows Service setup, Task Scheduler scripts, and dependency installers.
- `migration/` — SQLite inspection, field mapping, data transformation, and verification scripts.
- `verification/` — Post-install health checks and preflight scripts.
- `release/` — Staging folder for `GIGA-CHEMIST-SHOP2-PACKAGE`.
